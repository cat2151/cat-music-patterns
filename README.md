# cat-music-patterns

## Usage
- Used by cmrt-client-playground
  - Chord progressions
  - Tone.js sounds in Tone.js mode (when cmrt is not running locally)
- Used by cmrt
  - `surge-xt-patch-voicing.json` : For distinguishing chords/arpeggios on the keyboard screen (automatic detection result)
  - `surge-xt-patch-voicing-overrides.json` : Same purpose (manual correction result)

## Miscellaneous
