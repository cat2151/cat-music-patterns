# cat-music-patterns

## Usage
- Used by cmrt-client-playground
  - Chord progressions
  - Tone.js timbres/sounds when in Tone.js mode (i.e., when cmrt is not running locally)
- Used by cmrt
  - `surge-xt-patch-voicing.json` : For distinguishing chords/arpeggios on the keyboard screen (automatic detection results)
  - `surge-xt-patch-voicing-overrides.json` : Same as above (manual correction results)
- Used by cat-plugin-player
  - `surge-xt-patch-catalog.json` : A catalog for selecting Surge XT timbres in environments without cmrt (generated from Surge XT 1.3.4)
  - `surge-xt-fx-states.json` : Prepared states for each Surge XT Effects preset. Retrieved by SHA-256 of `.srgfx` (generated from Surge XT 1.3.4)
  - `surge-xt-start-delay.json` : Measured results for each Surge XT timbre, indicating whether playback is possible without issues by setting the post-instantiation delay to 0ms (generated by `measure-surge-start-delay` in cat-plugin-player)
  - `patch-pitch-tracking.json` : Measured results for each timbre (regardless of plugin) appearing in the drum percussion section, indicating whether changing the note also changes the pitch (`tracks_keyboard`). Timbres with `true` are moved to the lead section. Retrieved by `plugin_id`+`display`. `observations` are estimated frequencies for notes 48/49/55/60 (notes that could not be estimated are `null`).
    - Generation: In the `clap-mml-render-tui` repository, run `cargo run --release -p clap-mml-render-tui -- build-pitch-tracking --output ../cat-music-patterns/patch-pitch-tracking.json` (targets the cmrt catalog, and measures each timbre by launching `probe-pitch-tracking` from `clap-mml-play-server`).
